# دليل التشغيل السريع — منصة DentaCollab لطب الأسنان الرقمي

أهلاً بك! تم إعداد وتطوير النظام المتكامل لأكاديمية **DentaCollab** في بغداد وفق أعلى المعايير الهندسية والأمنية.

يتألف النظام من 3 أجزاء رئيسية متصلة بنفس مشروع الفايربيس (Firebase):
1. **تطبيق الطلاب والهواتف (Flutter)** في مجلد `apps/mobile/`
2. **لوحة التحكم الإدارية (Next.js App Router)** في مجلد `apps/admin/`
3. **الخلفية السحابية وقواعد الأمان (Firebase Functions & Rules)** في مجلد `firebase/`
4. **الموقع التعريفي العام المرجعي (Vite Reference)** المحفوظ في جذر المشروع.

---

## 🚀 تشغيل لوحة التحكم الإدارية (Admin Dashboard)

1. الانتقال إلى مجلد لوحة التحكم:
```bash
cd apps/admin
```
2. تثبيت الحزم (إن لم تكن مثبتة):
```bash
npm install
```
3. تشغيل خادم التطوير:
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3001` (أو الرابط المطبوع).
- تصفح مسارات:
  - `/login`: تسجيل دخول المشرف
  - `/dashboard`: مؤشرات التسجيل والدفعات
  - `/courses`: إدارة الدورات التدريبية
  - `/attendance`: ماسح بطاقات الـ QR وتسجيل الحضور الميداني
  - `/notifications`: منشئ الإشعارات الثنائية اللغة (FCM)

---

## 📱 تشغيل تطبيق الهاتف للطلاب (Flutter App)

1. الانتقال إلى مجلد التطبيق:
```bash
cd apps/mobile
```
2. جلب الحزم وفحص الكود:
```bash
flutter pub get
flutter test
```
3. تشغيل التطبيق على المحاكي أو الجهاز المتصل:
```bash
flutter run
```
يحتوي التطبيق على التبويبات الخمسة الرئيسية:
- **الرئيسية**: المسارات التخصصية (Exocad, Exoplan, 3D Printing) وأحدث الدورات.
- **الدورات**: تصفح البرامج والمناهج وتأكيد حجز المقاعد.
- **تعلّمي**: متابعة المقاعد المحجوزة واستعراض بطاقة الدخول الرقمية المشفرة **QR Entry Pass**.
- **الإشعارات**: صندوق بريد داخلي دائم لحفظ التنبيهات.
- **حسابي**: الملف الشخصي، والمساعد الأكاديمي الذكي (AI Assistant)، وتفاصيل التواصل بمقر بغداد.

---

## ☁️ تشغيل وتجربة دوال الفايربيس (Cloud Functions)

1. الانتقال لمجلد الدوال:
```bash
cd firebase/functions
npm install
npm run build
```
2. تشغيل محاكيات الفايربيس محلياً:
```bash
firebase emulators:start
```

## 🔐 تهيئة المشرف العام الأول (Super-Admin Bootstrap)

لترقية أو إنشاء أول حساب مشرف عام يتمتع بكافة الصلاحيات وحقن الـ Custom Claims:
```bash
npx ts-node scripts/bootstrap-admin.ts admin@dentacollab.org MyStrongPassword2026 "مدير الأكاديمية"
```
